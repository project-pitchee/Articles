## 📚 知识库模块分布 (8 大核心模块，共 49 篇)

### 🔹 Module 01: 算法规则判定 (Engine Rules - 15 篇)
深入剖析 Pitchee 核心评分算法的触发保护机制与硬封顶判定：
- `RULE-PASS-BOOST-01/02`: Pass Boost 协同突破加分与长篇生活实战
- `RULE-HIGH-F0-STYLIZED-01/02/03`: 30分封顶排查、SOVTE吸管吹唇、声带边缘M1/M2转换
- `RULE-HIGH-F0-MALE-01/02/03`: 59分封顶突破、声道体型感 (VFP)、元音变色提亮、摆脱卡通音
- `RULE-LOW-F0-NATURAL-01/02`: 59分低音封顶、CT肌温和激活、中性音区女性化补偿
- `RULE-LOW-F0-STYLIZED-01/02`: 20分健康保护卡点、下压喉结解绑、打哈欠叹气外喉肌松绑
- `RULE-F0-UNAVAILABLE-01/02`: 告别耳语练声危害、从纯气流到纯净实声的发声起始
- `RULE-CONTINUOUS-01`: 连续评分公式与各指标协同进展

### 🔹 Module 02: 综合得分区间 (Score Ranges - 8 篇)
按测试得分区间量身定制阶段性目标与心理建设：
- `SCORE-STARTER-01/02`: 面对 50 分以下拆解声学生理微习惯、嗓音性别焦虑自护与客观解耦
- `SCORE-MID-01/02`: 60 到 75 分平台期突破、15 分钟番茄钟微日程表与停练红线
- `SCORE-ADVANCED-01/02`: 80 到 90 分消除播音腔与假面感、语速韵律三拍子停顿
- `SCORE-MASTER-01/02`: 90 分全天候生活自动化、长期嗓音卫生与咽喉反流 (LPR) 预防

### 🔹 Module 03: 声学单项指标 (Acoustic Dimensions - 10 篇)
针对单项声学指标偏低或异常时的专项攻坚：
- `METRIC-PITCH-HIGH-01`: 避免过犹不及，寻找黄金频段 190–220 Hz
- `METRIC-PITCH-MONOTONE-01`: 普通话四声韵律起伏，拯救机械音
- `METRIC-PITCH-UNSTABLE-01`: 腹式呼吸与声带张力微调，提升音准稳定性
- `METRIC-VFP-DARK-01`: 舌背隆起与咽腔缩小，共鸣对齐度提亮
- `METRIC-VFP-NASAL-01`: 捏鼻自查法，软腭闭锁与真伪共鸣辨析
- `METRIC-VFP-THIN-01`: 防止声音单薄如纸，找回声音骨架与闭合抗阻
- `METRIC-VOLUME-PROJECTION-01`: 不挤喉咙的前提下增强响度与声音投射力
- `METRIC-DURATION-SHORT-01`: 胸腹联合呼吸与慢呼气训练，解决录音时长不足
- `METRIC-NATURAL-LOW-01`: 声带过度撞击与声门漏气消除，重塑自然度
- `METRIC-NATURAL-TENSION-01`: 喉外肌过度活动综合征 (MTD) 排查与紧急干预

### 🔹 Module 04: 男性向发声 (Masculine Voice - 5 篇)
面向 FTM 跨性别男性与非二元发声者的嗓音男性化指南：
- `MASCULINE-BASICS-01`: 扩大声道容积与胸腔共鸣协同
- `MASCULINE-LARYNX-01`: 避免暴力压喉坏嗓，松弛降低喉头的正确方法
- `MASCULINE-INTONATION-01`: 男性语调特征：平稳沉着与着重降调结构
- `MASCULINE-PRE-T-01`: 未用睾酮激素 (Pre-T) 的声音降低指南
- `MASCULINE-ON-T-01`: 睾酮变声期间的破音与声带水肿防护

### 🔹 Module 05: 中性与多元探索 (NonBinary Exploration - 2 篇)
跳出二元对立的探索：
- `NONBINARY-EXPLORE-01`: 在 145–165 Hz 音区探索中性多元配方
- `NONBINARY-FLUIDITY-01`: 声线自由切换指南与三档变速箱法则

### 🔹 Module 06: 引导练习与复测 (Guided Practice A/B - 3 篇)
针对 A/B 复测与自评困惑的科学归因：
- `PRACTICE-AB-DROP-01`: Take B 得分暂时下降：动作重塑期的正常波动（U型曲线）
- `PRACTICE-AB-SUBJECTIVE-01`: 听感更接近目标但分数没变的原因（双轨互补决策）
- `PRACTICE-AB-UNSURE-01`: 听辨训练三步通关：从听着迷茫到精准自察

### 🔹 Module 07: 录音环境与质量 (Recording Quality - 2 篇)
确保移动端麦克风采集成品达到专业声学输入标准：
- `QUALITY-CLIPPING-01`: 消除数字削波截断与防喷麦 45 度摆放法则
- `QUALITY-ENVIRONMENT-01`: 排除环境杂音、距离衰减与无线耳机降噪伪声

### 🔹 Module 08: 发声卫生与临床安全 (Health & Clinical - 4 篇)
将生理健康置于首位：
- `HEALTH-REDLINE-01`: 刺痛、干涩与嘶哑失声的紧急处置与“四绝不”红线
- `HEALTH-HYGIENE-01`: 嗓音卫生全书：水分补给、反流管理与科学练后冷身
- `HEALTH-CLINICAL-01`: 何时寻求嗓音支持专家与咽喉科医生专业帮助，及手术客观认知
- `HEALTH-TWVQ-01`: TWVQ-SC 跨性别女性嗓音问卷与生活质量自评量表

## 🛠 构建与集成 (Build & Integration)

本仓库提供编译脚本，可一键将全量 Markdown 文章及元数据编译为 iOS App 直接解析的 JSON 资源：

```bash
python3 build-voice-training-library.py
```

生成文件：
- `voice-training-library.json`: 包含所有文章详情、解析后的各小节（含 SF Symbol 绑定）及元数据。
- `voice-rule-matching-matrix.json`: 17 个规则维度的智能匹配索引。

在 Pitchee iOS App 中，通过 `VoiceTrainingLibraryStore` 与 `VoiceLibraryMatcher` 实现根据用户每次录音的算法特征矩阵进行精准匹配推荐，并支持通过 `VoiceTrainingLibraryBrowserView` 全库浏览。
