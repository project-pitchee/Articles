# 【声门闭合】从气流到实声：声门稳定闭合与有效发声起始（Onset）

- **适用场景**：用户录音经常缺失基频（触发 `f0_unavailable`），或者声音带有极重漏气感（Breathiness）、稍微说话就气喘吁吁。
- **用户痛点**：发声漏气严重、声带边缘无法稳定靠拢振动，声音虚弱无力导致无法稳定检出基频。
- **生理机制**：杓状软骨内收肌群（侧环杓肌 LCA、杓间肌 IA）的闭合协调机制。
- **核心目标**：从无声漏气中解脱，掌握“软起音（Simultaneous / Soft Onset）”，建立干净、平稳、无爆破音的实声声门闭合。

---

## 一、声学机制与算法原理

声带开始发声的瞬间被称为**发声起始（Onset）**，它直接奠定了整句话的声门闭合质量：
1. **硬起音（Hard Glottal Attack）**：
   - 先将声带死死咬闭，肺部猛推气压，最后“啪！”地炸裂冲开；
   - 听感：尖锐粗暴、极具撞击感，长期使用会导致声带黏膜充血小结；
2. **软漏起音（Aspirate / Breathy Onset）**：
   - 气流先行流逝，声带迟迟合不拢，声音伴随大量“嘶嘶”漏气声；
   - 听感：无力、苍白、缺乏支柱，在算法中容易丢失基频；
3. **协调软起音（Simultaneous / Easy Onset）——黄金标准**：
   - 气流到达声门的同一千分之一秒，两侧声带轻柔、完美地相迎闭合；
   - 听感：如同水滴融入平静水面，既不漏气，也不撞击，平稳输出纯净基频。

## 二、症状自查与代偿排查

### 声门闭合与起音模式自查排查
1. **“硬碰撞（Hard Attack）”代偿排查**：
   - 朗读以元音开头的字（如“阿姨”、“爱”、“安”）：发音前是否喉部先死死闭气、随后猛烈炸开发声？
   - 频繁硬起音会导致声带游离缘微充血，算法波形会呈现尖锐杂乱的瞬态脉冲；
2. **“过度漏气（Breathiness）”代偿排查**：
   - 手背放在唇前 3 厘米处发单音：手背是否感受到持续猛烈的高速热风喷射？
   - 单音维持时间若小于 5 秒，说明声门后部（软骨间部）存在明显闭合漏气缝隙（Glottal Chink）；
3. **耳语代偿排查（Whispering Trap Check）**：
   - 自查是否因为害怕自己的“男声”而长期使用气声耳语说话？耳语时声带前端闭合、后端大开，声带肌被迫长期处于非自然剪切受拉状态，极易导致失声。

## 三、训练动作与实操指南

### 步骤 1：“呵气变声”平滑过渡法（H-to-Vowel Glide）
1. 先发出轻柔长呼气：“Haaaaa……”（此时无声带振动）；
2. 保持气流匀速流淌，极其轻柔地将声带边缘靠拢，渐渐过渡为微弱实声：“Haaa---ahhh”；
3. 仔细感受声音从纯气流平滑变身为轻柔实音的临界点；
4. 这个临界点就是最健康的“声门轻闭合点”。

### 步骤 2：半咬唇闭合感知（Semi-Labial Closure）
1. 轻轻咬住下唇（如同发英文字母 /v/）；
2. 平稳呼气，发出持续的“Vvvvvv……”蜂鸣；
3. 由于嘴唇分担了气流阻力，声带可以在毫无压力的状态下实现 100% 紧密接触；
4. 随后移开嘴唇，保持相同的喉内闭合感，朗读句子。

### 步骤 3：声带闭合耐力微测试
- 尝试发一个平稳的“/a/”音，在不换气的前提下持续 8–10 秒；
- 如果 3 秒内就漏光了所有肺活量，说明声带闭合间隙过大，需重新进行吸管水泡或蜂鸣练习。
