# 理解 20 分上限：把模型结果与身体感受分开

- **适用场景**：女性向结果显示 low_f0_stylized_cap。
- **适用人群**：因综合分较低而困惑，想确定下一步观察重点的用户。
- **核心目标**：说明分支含义，避免由低分推断喉部障碍。
- **修订日期**：2026-10-05

## 一、理解这项主题

当前女性向规则在有效 F0 ≤ 165 Hz 且自然分 < 50 时匹配 low_f0_stylized_cap，最终分不超过 20。这里的“低”相对的是产品边界；“stylized”是代码中的规则标识，不是病名或对用户声音的价值判断。

自然分估计相对日常说话的听感与刻意造作、风格化程度。它不识别气道是否受阻，也不能诊断肌紧张性发声障碍、声带水肿或声门闭合问题。该上限是算法设计，不能称为身体通过 App 求救的信号。

低分可能发生在有意选择的低音角色朗读，也可能与模型参考范围或输入条件有关。模型对特定声音也可能反复误判，因此低分不能解释具体成因。若推荐与自己的体验和目标不符，可以跳过，不必把结果归因为训练不足。

## 二、练习前的观察

先检查文本是否完整、录音是否清楚、设备和环境是否改变，再回听这段声音是否符合本次目的。

身体感受另行记录：是否疼痛、发声明显费力或持续嘶哑？这些情况值得减少负荷并寻求评估，与分数高低无关。若存在呼吸困难，应及时求助，而不是继续录音确认分支。

## 三、可尝试的方法

1. 用平常的说话方式读一段熟悉短句，暂时不追求音高或音色变化。
2. 想再探索时，每次只选一个容易感知的目标，例如说得更清楚或更接近日常交谈。
3. 让下颌、舌头和呼吸自然配合；不按压、牵拉或左右移动喉部，也不用吞咽后的姿势“定位”声音。
4. 用同句回听比较是否更符合个人偏好，并允许结果没有变化。无需借助最小音量、长期哼鸣或其他固定方案“重置”身体。
5. 如果多种尝试都让说话更费力，就结束本次练习。回到熟悉的声音不等于失败，也不需要靠更低或更高的分数证明自己。
