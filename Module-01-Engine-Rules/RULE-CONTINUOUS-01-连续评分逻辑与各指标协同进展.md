# 你的综合分是怎么算出来的

- **适用场景**：刚拿到一个综合分，想知道它是怎么算出来的；或者换了声音偏好，发现分数算法不一样了。
- **适用人群**：对分数好奇、想知道接下来该盯着哪一项练的人。
- **核心目标**：看懂分数由哪三部分组成，知道每一项偏低时该观察什么。
- **修订日期**：2026-10-10

## 一、理解这项主题

你的综合分由三个输入算出来：**音色分**、**自然分**、**音高**。先说清它们各在量什么：

- **音色分**：模型给你的音色打的分，越高表示越接近"女性向参考特征"。当个参考就行，具体练什么还是以你的耳朵和目标为准。
- **自然分**：模型判断这段录音听起来像不像日常说话。分低不代表嗓子有问题——一段音色明亮、音高偏高但朗读腔很重的录音，就会音色分高、自然分低，这很正常。
- **音高（F0）**：检测到的平均基频，单位是 Hz，只用来辅助看音高。

女性向的权重是：音色分占 50%、自然分 20%、音高 15%，剩下 15% 看三项一起的表现。这个配比是产品设计时定的，不是"人听声音辨性别时各占多少"的科学结论，别拿它当生理依据。

还有几个容易误解的点：

- **三项可以不同步**。音色分高、音高高，但自然分低，完全可能同时出现，不代表你哪里"练错了"。
- **音高超过 200 Hz 不再加分**。公式里音高这一项到 200 Hz 就到顶了，再往上飙，分数不会更高，嗓子只会更累。
- **男性向是另一套公式**。60 分起步，按音高和音色分上下浮动，自然分目前不参与。不是把女性向的公式反过来用。

**技术细节**：女性向基础分 \(B=100(0.50S_r+0.20N_r+0.15F_r+0.15S_rN_rF_r)\)，其中 \(S_r=S/100\)，\(N_r=\operatorname{clamp}((N-40)/50,0,1)\)，\(F_r=\operatorname{clamp}((F_0-110)/90,0,1)\)，S、N 先限制在 0–100，clamp 表示把计算值限制在上下界之间。举个例子：音色分 70、自然分 75、音高 180 Hz 时，四项分别贡献约 35、14、11.67、5.72 分，基础分约 66.38。男性向公式为 \(B=F=\operatorname{clamp}(60+25d_{F_0}+15d_{\mathrm{VFP}},0,100)\)，其中 \(d_{F_0}=\operatorname{clamp}((165-F_0)/75,-1,1)\)，\(d_{\mathrm{VFP}}=\operatorname{clamp}((50-S)/50,-1,1)\)；音高缺失时令 \(d_{F_0}=0\)。

## 二、练习前的观察

光有基础分还不够。女性向拿到有效音高后，会按顺序匹配下面这些规则，第一个命中的生效：

| 你的情况 | 命中的规则 | 意味着什么 |
|---|---|---|
| 音高 >165 Hz，自然分 >80，音色分 >50 | pass_boost | 可能拿到一个加分候选，和基础分取高的那个 |
| 音高 >165 Hz，自然分 <50 | high_f0_stylized_cap | 最终分不超过 30 |
| 音高 ≤165 Hz，自然分 ≥50 | low_f0_natural_cap | 最终分不超过 59 |
| 音高 ≤165 Hz，自然分 <50 | low_f0_stylized_cap | 最终分不超过 20 |
| 音高 >165 Hz，自然分 ≥50，音色分 <50 | high_f0_male_cap | 最终分不超过 59 |
| 都不符合 | continuous | 最终分就等于基础分 |

"上限"的意思是：最终分取当前分数和上限里较小的那个，不代表你这次一定会被压到上限值。

为什么要有这些上限？设计意图是防止某一项的高分把其他项的问题盖过去。比如音色分很低时，光靠高音高和高自然分是补不回来的；反过来，音高偏低时，高音色分也带不动总分。所以音色分权重最大（50%），但它自己决定不了最终结果。

**技术细节**：pass_boost 的提升强度 \(t=\min((F_0-165)/25,(N-80)/20,(S-50)/30,1)\)，候选分 \(P=60+40t\)，最终分取 \(\max(B,P)\)。规则名显示 pass_boost 不等于这次一定加了分——只有 \(P>B\) 时才会真正加分（此时 score_boosted 为真）。另外，score_limited 只在上限确实把你的分数压低了时才为真。音高缺失时返回 f0_unavailable，基础分和最终分都直接取音色分。

## 三、可尝试的方法

别急着"刷分"。先拿一次录音，把三个输入和最终分抄下来，对照上面的表看看自己落在哪一行——这就是你这次的观察起点。

1. 先写一个听得出来的小目标，比如"把每个字都重读的朗读腔，改成跟朋友说明安排的语气"。
2. 用同一句话录两版做对比。A 版按原来的方式说："我明天下午有空，可以一起喝杯茶。"B 版只把重点放在"明天下午"，其他字按聊天语气带过。设备、距离、环境保持一致。
3. 先回听哪版更符合目标、哪版说起来更省力，再看分数。把"听感更好但分数没涨"也如实记下来——这条记录比分数有用。
4. 下次用同样的句子再比一次；再找一次真实对话，看看这种说法用不用得上。练习记录和日常使用是两回事，分开看。
