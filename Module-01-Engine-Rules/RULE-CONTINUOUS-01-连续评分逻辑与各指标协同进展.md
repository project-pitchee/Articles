# 【评分透视】读懂 Pitchee 的连续评分逻辑：基频偏差与 VFP 偏差的综合协同

- **适用场景**：Pitchee 算法处于 `continuous` 规则（无硬性 Cap 封顶或额外 Boost，分数完全由连续声学公式计算）。
- **用户目标**：深入理解自己录音得分背后的底层数学与声学逻辑，明确下一步提分的核心抓手。
- **核心认知**：发声训练不是单向盲目的“冲指标”，而是基频、共鸣与自然度各维度的加权平衡游戏。

---

## 一、声学机制与算法原理

在女性向声音偏好下，基础分（Base Score）的计算遵循四维加权多项式：
$$\text{Base} = 100 \times \left(0.50\,S_r + 0.20\,N_r + 0.15\,F_{0r} + 0.15\,S_r\,N_r\,F_{0r}\right)$$

### 四大项声学权重解读：
1. **共鸣对齐度权重高达 50%（$0.50\,S_r$）**：
   - 公式中比重最大的一项！这印证了声学事实：**共鸣是跨性别嗓音女性化的半壁江山**；
   - 即使你的音高一般，只要声道形态（VFP）调整到位，底分就已经有了扎实保障；
2. **自然度占比 20%（$0.20\,N_r$）**：
   - 确保声音有真实人声质感，杜绝机械化假音；
3. **基频占比 15%（$0.15\,F_{0r}$）**：
   - 基频从 110 Hz 到 200 Hz 线性归一化，超过 200 Hz 即达到该项满分（$F_{0r} = 1.0$）；
4. **协同增益项占比 15%（$0.15\,S_r\,N_r\,F_{0r}$）**：
   - 只有当共鸣、自然度与基频**三者同时优秀**时，该乘积项才会爆发最大能量；
   - 一旦其中某一项归零，协同奖励将彻底清零！

## 二、症状自查与代偿排查

在男性向声音偏好下，Core profile 采用对称反向偏差模型：
$$\text{Base} = \text{Final} = \min\left(100, \max\left(0, 60 + 25\,d_{F_0} + 15\,d_{\text{VFP}}\right)\right)$$
其中：
- $d_{F_0} = \operatorname{clamp}\left(\frac{165 - F_0}{75}, -1, 1\right)$（以 165 Hz 为中线，音高越低得分越高，在 $\le 90\text{ Hz}$ 达饱和满分 $+25$）；
- $d_{\text{VFP}} = \operatorname{clamp}\left(\frac{50 - \text{VFP}}{50}, -1, 1\right)$（VFP 越低，说明声道越宽阔雄浑，在 $\le 0$ 达饱和满分 $+15$）；
- **基准分 60 分**：在双中点（165 Hz, VFP 50）基础分为 60。

## 三、训练动作与实操指南

1. **先做大项，再抓协同**：
   - 如果你的 VFP 只有 30，不要花整天时间去抠那微弱的 5 Hz 基频，集中精力练习舌位前高与声道缩短；
2. **守住自然度底线**：
   - 自然度一旦跌落 50，极易触碰判定封顶（Cap 20 或 Cap 30），导致多项努力化为乌有；
3. **重视趋势中位数**：
   - 发声状态受早晚、水分、情绪波动影响很大。关注 Pitchee 趋势图中的“每日中位数”，而非单次偶然出现的最高分。
