# 理解 pass_boost：从短句尝试过渡到较长表达

- **适用场景**：女性向结果显示 pass_boost，希望了解规则或练习更长的内容。
- **适用人群**：短句已较接近个人目标，准备观察多句说话表现的用户。
- **核心目标**：分清规则命中、实际加分和日常迁移，让练习难度按个人情况变化。
- **修订日期**：2026-10-05

## 一、理解这项主题

当前女性向计算在 F0 > 165 Hz、自然分 > 80、音色分（VFP）> 50 时匹配 pass_boost。它先计算连续基础分 B，再计算：

$$t=\min((F_0-165)/25,(N-80)/20,(S-50)/30,1),\quad P=60+40t$$

其中 S 是音色分、N 是自然分，均先限制在 0–100。最终分取 B 与 P 的较大值。只有 P > B 才实际提升分数，并令 score_boosted 为真；**规则显示 pass_boost 不等于这次一定加了分**。基础分完整定义见同模块的连续评分文章。

这项规则在三项输入都进入指定范围后，将它们相对各自门槛的增量按公式折算，取最小值决定候选分的强度，鼓励模型读数共同变化。例如 S = 90、N = 90、F0 = 180 Hz 时，B 约为 87.17，P 为 80，最终分仍为 87.17；S = 80、N = 100、F0 = 190 Hz 时，B 为 84，P 为 100，最终分才提高到 100。两例都命中 pass_boost，示例数值仅用于演示计算。

它提供的是产品反馈，不是进入更难练习的资格认证。模型可能误判，分数也不能判断嗓音健康。是否练习较长表达，主要看短句是否符合个人目标、说起来是否方便，以及你是否有这样的使用需求。

短句和较长表达是不同任务。增加句子后，还要组织内容、安排停顿，并在注意意思时使用偏好的声音，因此需要单独观察。

## 二、练习前的观察

确认自己准备练的是哪种场景：读段落、讲述事情还是即兴回答。比较前后时使用同一种任务，不要把短句和长段的分数差全部当成训练效果。

观察能否在需要时自然换气、说完后是否费力，以及自己是否喜欢这种声音。句尾下降和换气时的声音变化可以是正常表达，不需要全程保持固定舌位。

## 三、可尝试的方法

1. 先说“今天很凉快”，再扩展为“今天很凉快。/ 我想出门散步。/ 你要一起吗？”斜线表示可停顿的位置，也可以按自己的呼吸需要调整。
2. 每句结束后自然换气，下一句重新开始，不必一口气把三句连完。回听第二、三句是否仍清楚，自己是否仍喜欢它们。
3. 朗读舒适后，收起文字，回答“你今天有什么安排？”让意思相近即可。若需要同时顾及的事情太多，回到两句，或结束本次练习。
4. 若想记录更长的进展，可使用自己选择的可保存录音工具。Pitchee 当前引导练习音频是临时保存，结束或替换后会清理，不能默认隔天仍可回听。
5. 同句 A/B 可帮助比较本次两种尝试，不能验证全天表现。是否增加长度由使用需求和反应决定，不以 pass_boost 或固定分钟数作为依据。
