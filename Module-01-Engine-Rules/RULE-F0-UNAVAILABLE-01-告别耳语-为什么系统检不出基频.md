# 音高没有检出：先检查录音，再区分耳语与有声发音

- **适用场景**：音高显示缺失，女性向结果采用 f0_unavailable。
- **适用人群**：希望了解空白音高含义，或只能在较安静环境练习的用户。
- **核心目标**：找到可供分析的录音方式，不把音高缺失理解成身体诊断。
- **修订日期**：2026-10-05

## 一、理解这项主题

基频 F0 描述有声片段中近似周期重复的频率。普通耳语主要依靠气流噪声，通常没有与有声发音相同的稳定基频，因此听得见字词也可能无法估计音高。轻声与耳语并不完全相同：轻声仍可带有周期性发音。

音高缺失还可能涉及录音过轻、噪声、片段过短、声学变化较大或模型适用范围。当前录音分析只纳入置信度大于 0.9、估计音高在 75–600 Hz 的帧。这是筛选规则，不是人体音域，也不能反推未通过的原因。

在女性向规则中，缺少有效 F0 时基础分和最终分回退为音色分（VFP）。男性向则在其连续公式中将音高偏差项置为零。两种回退都没有“补测”出缺失音高；作为回退使用的音色分本身也可能误判，不能自动成为下一步训练依据。

## 二、练习前的观察

先回听是否能清楚听见完整话语，再查看录音质量提示。没有音高与完全没有检测到语音是不同情况，不要为了消除空白而不断增大音量。

如果是隐私限制使你只能耳语，可以把此时的任务改为听辨、阅读或不发声地熟悉文本。需要休息嗓音时，减少用声比强求某一种耳语方式更容易执行。

## 三、可尝试的方法

1. 在能够自在说话的环境，用日常音量说两三句完整的话。保持设备稳定，避免遮住麦克风；先回听确认字词清楚、音量可听。
2. 作为不计分的体验，轻轻发一个容易完成的“嗯”，再接“嗯，我知道了”。听一听“嗯”里是否有可辨别高低的音调，与只呼气的声音作区分。
3. 再按普通说话方式录制完整话语。如果有声短句能显示音高，而原录音没有，可先检查两次内容和输入差异；如果仍缺失，就把结果记为暂不可用，不必不断提高音量或改变喉部动作。
4. 若发声本身持续费力、疼痛或嘶哑，暂停练习并寻求合适的专业支持。只有数据缺失、身体没有不适时，可以先转做回听或其他不依赖音高读数的任务。
